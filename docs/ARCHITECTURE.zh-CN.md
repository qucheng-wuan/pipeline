# 数据流与模块边界

本项目的推理输入是 RGB 和已知相机内参 K，输出单位为米的原生分辨率光轴深度。
第一阶段冻结，第二阶段使用完整的已训练 LIDF/SPVNAS 参数。

## 推理

1. `transparent_depth.cli` 校验发布配置、资产清单、所选 checkpoint 和实际权重的身份。
2. 第一阶段子进程从 RGB 实时运行专家、V2 融合和第 8 轮可训练拉普拉斯适配器，得到预测深度 P。
3. 第二阶段子进程将 RGB、P 和 K 按原训练规则变换到 320×240，运行 LIDF/SPVNAS。
4. 未得到有效修正的像素保留 P；结果按原插值规则恢复到 RGB 原生分辨率。

GT 深度、GT 透明掩码和传感器深度不属于推理接口。第一阶段也不读取 K。
两阶段使用不同的固定 PyTorch 环境，由 CLI 通过文件传递 P，避免混用稀疏算子运行时。
`CUDA_VISIBLE_DEVICES` 由调用者指定，并原样传给两个子进程。

## 训练输入与监督目标

设 P 为冻结第一阶段预测，G 为 GT 深度，M 为 GT 透明区域掩码。训练阶段的第二阶段输入为：

```text
透明区：P
有效 GT 背景区：alpha * G + (1 - alpha) * P
无效 GT 区：P
监督目标：G
```

80 轮历史训练采用 20／30／30 轮课程：alpha 先为 1，中间随优化步线性降到 0，最后为 0。
早期 60 轮、20／20／20 课程属于前一项实验；本仓库整理的是后来获准的 SPVNAS 80 轮协议。
透明区始终使用 P。该输入混合不会将监督目标改成 P。
课程匹配验证用于观察各阶段拟合；全预测输入验证用于观察部署条件。
历史训练的最终选模使用纯预测输入验证，原验证选模记录予以保留。

`prepare_stage2_data` 将 RGB/K/P 输入缓存与 GT/mask 标签缓存分别封存。
合同绑定第一阶段生产者、20 项资产、源码及缓存字节身份，恢复训练时再次核验。
训练入口是 `transparent_depth.train_stage2`，3 卡和 8 卡配置均明确记录批量和每轮更新数。

## 发布轮次与评估

本次按用户指定，对第 1–80 轮全部使用完整 1,226 张、纯 P 输入进行预测，
以原生分辨率、逐图宏平均的透明区域 MAE 最低者作为发布轮次。
预测阶段不读取标签；全部预测封存后，独立评估进程才读取 GT。
这属于测试集参与选模，报告明确保留该标记。

报告同时保留第一阶段原生输出、第一阶段缩放往返对照和第二阶段输出，
并分别列出全图／透明／背景、真实／合成、原 521 张测试子集及几何指标。
透明区域选优不能保证其他指标同时改善。

当前发布验收采用 `training_release`：完整 1,226 张历史封存 P 与便携 Stage2 同 P
预测、指标对照，以及 3 例实时第一阶段对照、1 例目录迁移、12 张新 RGB 预测，
再用这些真实预测完成单卡／双卡各 9 次更新、三阶段课程和中断恢复验收。
完整 1,226 张实时 RGB 专家链未重新计算；报告只有两条全量链，不生成第三条 live 指标。
这些检查支持模型、损失、输入处理及训练入口的可用性，不保证重新训练后的分数相同。

第一阶段保留原 CUDA scatter 归约算子与权重。用户已确认固定数值验收：42 项上游及
V2 输入等字段要求 exact；4 项米制深度输出各自最大绝对差≤5e-5 m、平均绝对差≤1e-6 m；
9 项非米制中间量只检查 schema 和有限值，不宣称 exact。原零容差失败与重复性证据保留。
第二阶段原 1e-6 m 逐像素门槛实际未通过：约 9416 万个低分辨率像素中有 5 个超限，
最大差约 56.46 mm；其余像素只存在浮点末位差异，修正掩码全部一致。旧版普通推理自身
复跑也会因近并列候选的硬 argmax 翻转产生相同跳变。原失败和阈值完整保留，没有修改算子或权重。
按用户要求的近似训练效果范围，另立明确的质量接受记录：逐图平均预测差最大不足 0.001 mm，
全部 18 个分区 MAE 变化最大约 0.000003381 mm，透明 MAE 变化约 0.000000503 mm。
这些是完整评测实测差异，不是逐像素一致或未来重训得分相同的保证。
报告工具默认 `full_live` 仍要求完整第三链，
只有显式选择 `training_release` 并提供实际验收凭据时才采用上述范围。
额外的 `--cached-quality-acceptance` 必须绑定原严格失败、完整指标、自重复诊断和明确审核，
默认严格路径不变；第一阶段的已确认数值标准不能用来替代第二阶段的独立检查。

## 文件归属

| 位置 | 职责 |
|---|---|
| `src/transparent_depth/` | 资产、环境边界、公开推理接口、数据准备与训练入口 |
| `src/native_fusion/`、`src/laplacian_train/` | 第一阶段保留的数值实现 |
| `src/v2_lidf/` | 第二阶段模型、几何、损失及所需内核 |
| `third_party/` | 固定上游源码和许可证 |
| `configs/` | 发布模型身份与明确的训练配置 |
| `provenance/` | 权重、源码及历史实验来源 |
| `reports/` | 全量选模、效果对照及发布验证证据 |

历史路径只作为来源记录保留。公开推理和新的数据准备／训练流程使用显式路径，
不依赖原实验目录或已有专家缓存。安装、训练命令见同目录的两阶段复现文档。
